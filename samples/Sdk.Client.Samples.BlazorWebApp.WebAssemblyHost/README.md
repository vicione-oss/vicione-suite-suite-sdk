# Sdk.Client.Samples Blazor Web App WebAssembly Host

## Overview

This project implements the WebAssembly host required for using
[render mode](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/render-modes) `Interactive WebAssembly`
or `Interactive Auto` in project `Sdk.Client.Samples.BlazorWebApp`.

It is based on the `.Client` project generated by Visual Studio templates when a new Blazor Web App is created.
