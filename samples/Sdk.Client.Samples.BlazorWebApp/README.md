# Sdk.Client.Samples Blazor Web App

## Overview

This project is a Blazor Web App, hosting samples for the `Sdk.Client` namespace.

It can be run with either the [render mode](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/render-modes) `Interactive Server`
or `Interactive WebAssembly`. The launch profiles have been named accordingly.

The WebAssembly host required for any render mode involved with WebAssembly,
is implemented in `Sdk.Client.Samples.BlazorWebApp.WebAssemblyHost`.
